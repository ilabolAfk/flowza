Flowza для Linux
================

Что это
-------
Локальный визуальный конструктор автоматизаций: сценарий собирается мышью
в браузере, запускается и показывает результат по каждой ноде.
Python и библиотеки уже внутри бинарника — устанавливать ничего не нужно.

Требования
----------
64-битный Linux с glibc 2.36 или новее (Debian 12, Ubuntu 22.04 и новее).
Бинарник собран на Debian 12 (bookworm).

Запуск
------
1. Распакуйте архив, например в ~/Flowza.
2. Дайте файлу право на запуск и запустите:

    cd ~/Flowza
    chmod +x Flowza
    ./Flowza

3. Откроется браузер на http://127.0.0.1:8765
   (если не открылся — введите адрес вручную).
4. Остановка — Ctrl+C в терминале.

Другой порт:      ./Flowza --port 8766
Без браузера:     ./Flowza --no-browser

Что где хранится
----------------
Папка данных: ~/.local/share/flowza (или $XDG_DATA_HOME/flowza)
  flowza_graph.json     — граф (создаётся при первом сохранении)
  flowza_settings.json  — настройки из окна с шестерёнкой
  flowza_runs.log       — журнал прогонов
  workspace/            — рабочая папка нод «Прочитать/Записать файл» и SQLite
Другой путь задаётся переменной FLOWZA_GRAPH=/полный/путь/graph.json.

Иконка в меню
-------------
В архиве есть flowza.desktop и flowza.png. Установка иконки в меню:

    mkdir -p ~/.local/share/applications ~/.local/share/icons
    cp flowza.png ~/.local/share/icons/flowza.png
    sed "s|Exec=flowza|Exec=$HOME/Flowza/Flowza|" flowza.desktop \
      > ~/.local/share/applications/flowza.desktop
    update-desktop-database ~/.local/share/applications

Настройки, история и отмена
---------------------------
* Шестерёнка на панели — настройки: пауза, таймаут, повторы, автосохранение,
  рабочая папка, SMTP, тема, приём вебхуков.
* Часы — история последних 50 прогонов, у каждого можно открыть результат.
* Во время прогона работает прогресс-бар и кнопка «Отменить».
* «Расписание» запускает граф по интервалу, пока приложение открыто.

Приём вебхуков
--------------
Адрес: POST http://127.0.0.1:8765/hook/<суффикс из ноды>
Без токена принимаются только запросы с этого компьютера. Для внешних:

    export FLOWZA_WEBHOOK_TOKEN=длинная-случайная-строка

и передавайте его заголовком X-Flowza-Token.

Отправка почты (нода «Отправить письмо»)
----------------------------------------
Пароль в графе не хранится, он берётся из переменной окружения:

    export FLOWZA_SMTP_HOST=smtp.yandex.ru
    export FLOWZA_SMTP_PORT=465
    export FLOWZA_SMTP_USER=robot@example.ru
    export FLOWZA_SMTP_PASSWORD=пароль-приложения

Порт 465 — SSL, 587 — STARTTLS.

Ограничения
-----------
* Нода «Запрос к ИИ» — заглушка: модель не вызывается, результат помечен stub.
* Ноды HTTP и входной вебхук не ходят на внутренние адреса, пока это не разрешено
  в настройках («Безопасность»).
* Файлы — только внутри рабочей папки, до 5 МБ; цикл — до 5000 элементов.
* Задержка блокирует прогон (максимум 300 секунд), отмена её прерывает.

Горячие клавиши: F5 — запуск, Ctrl+S — сохранить, Ctrl+Z/Ctrl+Y — отмена и повтор,
Ctrl+N — новый граф, Ctrl+O — перечитать файл, Delete — удалить выбранное.
